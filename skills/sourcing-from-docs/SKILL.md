# skill: sourcing-from-docs (v2 — learned from L-dfe4b08542)

Gather sources into research.md. Lesson from run r20260724-160746: a
research artifact was rejected as trivial (<300 chars). So:

- Produce a substantial `## Findings` section — at least a short
  paragraph per claim, never a bare bullet list.
- Every claim carries a retrievable source link; at least THREE
  independent sources before the draft stage can begin.
- If you cannot find three sources, say so explicitly rather than
  padding — an under-sourced dossier is an opinion.
