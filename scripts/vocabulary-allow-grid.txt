# The grid's own generic words, on top of vocabulary-allow.txt: Dutch interface defaults in i18n.ts that a site
# overrides through its schema's strings, and words a domain also happens to declare. One per line, with the reason.

# A record's basic parts, as every form and list names them
naam # a name field or the "Naam" of a view
titel # a record's title
soort # "Soort": the kind of a tile or a file
kleur # a column's colour
bron # a view's source dataset
adres # a web address, a published view's address
website # where a published view is embedded
toegang # who has access to a view

# Moving and choosing
volgende # next: page, period, record
andere # other: "andere velden", "andere wijzigingen"
wie # who: an assignment's holder, a history line's actor
wat # what: a history line's change
plaats # a place of a link (have/need), and the pin icon's name
plaatsen # places of a link
rol # the role a link place asks for
kandidaten # a place's candidates
actie # a declared action on a record
toegewezen # assigned, a link place's state
gepland # planned, a period's state
geblokkeerd # blocked, a calendar day's state
dag # a day in the calendar and its periods
agenda # the calendar export (.ics)

# Notes, history and files
notitie # a matrix cell's note
notities # the drawer's notes tab
bijgewerkt # "bijgewerkt": updated, a history line
bestanden # files: attachments
